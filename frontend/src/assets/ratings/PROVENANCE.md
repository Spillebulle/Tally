# Where these marks come from

Age-rating symbols, used to show the certificate a title actually carries.

**Copyright.** Every vendored file is in the **public domain**. Commons tags
them `PD-textlogo` / `PD-ineligible`: the symbols consist of simple geometry
and text, which does not meet the threshold of originality for copyright.

**Trademark.** The symbols are nonetheless registered trademarks of their
boards, and the Commons files carry the `trademarked` notice: *"This work
includes material that may be protected as a trademark in some jurisdictions.
If you want to use it, you have to ensure that you have the legal right to do
so."* Tally displays them descriptively — to state the rating a title was
given. Boards set their own terms for other uses; the BBFC, for instance,
licenses symbol use on VOD services under direct licence.

**Edits.** Some files carried `width`/`height` but no `viewBox`, so they would
not scale inside an `<img>`. A `viewBox` matching the declared size was added.
Nothing else in any vendored file was changed.

## Norway is a reconstruction, not a vendored file

Medietilsynet publish no free symbol file, so `no-*.svg` were **rebuilt** from
their own classification guidelines
(`230101_retningslinjer_aldersklassifisering_norsk.pdf`): the artwork was
decoded out of the PDF, the geometry measured off it (outer rule 1.6% of the
box, inner ring from 14.9% to 23.5%, glyph cap height 29.4%, centred) and the
colours sampled from the embedded palettes — `#6EB055` for A and 6,
`#E3D800` for 9 and 12, `#EB5C24` for 15, `#E30613` for 18. Four colours across
six levels is the board's own scheme, not a ramp.

The numerals are set in a system sans rather than Medietilsynet's own face, so
these are faithful but not pixel-exact.

## Deliberately not included

**Korea (KMRB).** Three of the four files on Commons are CC BY-SA 4.0, not
public domain. Share-alike on a bundled asset is a licence obligation the rest
of this directory does not carry, so the board is left to the age-disc
fallback.

**France, Ireland, Sweden, Denmark, Finland, Spain.** No free asset found.
