# Where these marks come from

Age-rating symbols vendored from Wikimedia Commons, used to show the
certificate a title actually carries.

**Copyright.** Every file below is in the **public domain**. Commons tags them
`PD-textlogo` / `PD-ineligible`: the symbols consist of simple geometry and
text, which does not meet the threshold of originality for copyright.

**Trademark.** The symbols are nonetheless registered trademarks of their
boards, and the Commons files carry the `trademarked` notice: *"This work
includes material that may be protected as a trademark in some jurisdictions.
If you want to use it, you have to ensure that you have the legal right to do
so."* Tally displays them descriptively — to state the rating a title was
given. Boards set their own terms for other uses; the BBFC, for instance,
licenses symbol use on VOD services under direct licence.

**Edits.** Five Kijkwijzer files carried `width`/`height` but no `viewBox`, so
they would not scale inside an `<img>`. A `viewBox` matching the declared size
was added; nothing else in any file was changed.

**Not covered.** Norway (Medietilsynet), France, Australia and others have no
free asset, and fall back to a plain age disc that is deliberately not anyone's
mark. See `lib/rating-systems.ts`.
